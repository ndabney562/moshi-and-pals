## Direction

Warm ivory surfaces, petrol teal navigation, mint primary actions, amber accents,
consistent rounded cards, clear typography and expressive illustrated portraits.
One primary Start Shift action; persistent Play / Providers / Locker / Board /
Leaderboard navigation. Preserve the existing gameplay and progression systems.

## Generation brief

Create a two-screen landscape mobile game presentation: title/home above and
Providers below. Reference the existing `public/assets/title.jpg` for the original
four doctors and clinic setting, and `providers-draft-01.png` for additional
provider hair, costume and palette. Use three-quarter illustrated menu portraits
instead of enlarging overhead gameplay sprites. Keep the clinic art unobstructed
by large menu panels. Use coherent navigation and currency displays on both
screens, one prominent Start Shift button, compact mode/difficulty selectors and
a secondary Today's Shift card. Feature Janeen on Providers with roster tiles,
Divine Coverage and All Specialties cards, and her approved 10,000 NPS unlock.
Avoid emoji, neon, debug text, browser/device chrome and dashboard styling.

Correction pass: depict Dharma as a middle-aged South Asian man with short black
hair, rectangular glasses and a white coat over a pink shirt/dark tie. Replace
the invented daily objective with “A fresh challenge, every day.”

## Implementation boundaries

- Balances are sample values; purchase availability must reflect actual saved NPS.
- The full roster has 11 providers; the seven shown illustrate roster styling.
- Portraits are proposed menu art, not replacements for gameplay sprites.
- Ability descriptions and prices must come from the existing game data.
- Final controls require responsive layouts, safe-area checks, keyboard/touch
  verification and the existing test gate. The raster image is not evidence that
  those controls work. Detailed portrait likenesses and small icons need an asset
  review before production use.
