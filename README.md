# Moshi and Pals

A comedic wave-survival game for iPhone. Dr. Eugene "Moshi" Moshkovich versus the germs.

**Play:** https://ndabney562.github.io/moshi-and-pals/ (on iPhone: open in Safari, Share → Add to Home Screen, then launch from the icon).

## Develop
```
npm install
npm run dev      # local server; open the printed URL (works on a phone on the same Wi-Fi)
npm run build    # type-check and build to dist/
npm run smoke    # phone-sized browser test of the build
```

Docs live in [`docs/`](docs/): design, architecture, assets, backlog, bugs, balance, changelog, contributions.
